# Lab 1

**[Optional]** If what is being submitted is an individual Lab or Assignment. Otherwise, include a brief one paragraph description about the project.

For this Lab I chose to scrape the League of Legends wiki to allow for searching and sorting champions by their Name, Class, release date and last updated version of the game.

I used Windows 11's build in Narrorator and Chrome Lighthouse to audit the accessibility of my search interface.

I found the screen reader worked very well with the search interface especically due to it reading off "22 results found." and "No results found. Try a different name or class, or clear the filters."
One thing I found problematic about the screen reader was how it would say "One result found, misspell" If you searched for a character with a strange name like  "Yuumi" or "Nunu" for example.

My search interface got a score of 100 from Chrome's Lighthouse test. I also made sure not to use any obscure colour choices as to not effect readability.
