# Lab 3

**[Optional]** If what is being submitted is an individual Lab or Assignment. Otherwise, include a brief one paragraph description about the project.

For this Lab I chose to base my api off the list of patients at the Vancouver Aquarium Marine Mammal Rescue Centre.

* *Date Created*: 05 11 2026
* *Last Modification Date*: 05 11 2026
* *Lab Gitlab URL*: https://git.cs.dal.ca/dubois/csci-3172
* *Render URL*: https://csci-3172-lab3-683v.onrender.com/

ENDPOINTS
  GET    /api/items          List all patients
  GET    /api/items/:id      Get one patient (e.g. /api/items/PV2684)
  POST   /api/items          Create a patient (JSON body, see below)
  DELETE /api/items/:id      Delete a patient (e.g. /api/items/PV2683)

GET requests can be opened in a browser. For POST and DELETE, use
Postman (or curl) and set the header Content-Type: application/json.

SAMPLE VALID POST BODY
  {
    "name": "Tofino",
    "species": "Harbour Seal",
    "admitted": "2026-09-10",
    "collectionSite": "Tofino",
    "reasonForAdmission": "Maternal Separation",
    "weightKg": 10.5,
    "status": "in care"
  }
